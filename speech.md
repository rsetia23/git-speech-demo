## Intro

* AGD: "Raise your hand if you've ever lost hours of work. A crashed laptop, a file you overwrote, or some project where the files all had the same name."
  * The undo button couldn't help since it only remembers the last few minutes of your work.
* I have seen this often as a Computer Science major when we working on project without a version management tool.
* Git allows anyone to safely experiment, colloborate, and undo history by saving a complete history of everyone's work.
* Think about it like a video game where you have a checkpoint, and Git allows you make these for your work.
* I will cover how Git allows you to maintain history, safe experimentation, and collaboration.

## Slide 2: Never Lose Work

* Commit is a save point, and Git keeps all of them forever.
* Go back to any version of your work.
* Risky change = making a branch so you don't affect the main version of the work.
* Idea fails? Drop it Idea works? Merge it with the main work.

## Slide 3: Work Together

* Group project chaos: emailed files, old copies, similarly named files
* With Git, everyone works at the same time on their own copy
* We can use pull requests to make sure changes are reviewed before combining them
* Nobody overwrites anyone
* Scale: Microsoft moved windows to Git, about 3.5k engineers on 3.5 million files.
* Cite: "According to a 2017 post on Microsoft's dev blog"
